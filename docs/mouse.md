# 鼠标操作对照（Jw_cad 帮助 vs 本软件）

依据：`C:\jww\Jw_cad.chm`（Jw_cad 自带帮助）里的「基本操作」「作図」「編集」「設定」「その他」各章。
**2026-11-02：下表的「不一样」「缺」已全部按 Jw_cad 改好**（测试：`tests/mouse_ops.rs`）。几点说明：

- 时钟菜单的命令用的是环境设定文件里的 `LD_AM` / `LD_PM` / `RD_AM` / `RD_PM`（及拖得远时的 `LD2_` 等）。
  帮助里标准时钟菜单只有图没有文字，所以非 AUTO 命令下也用这张表；右 AM 0・3・6・9 时为 0 时是读取（1/4 点・中点・偏移・线上点）。
- 双击照 Jw_cad：第一下后鼠标不动、再点一下就算双击，不看时间；能双击的地方，单击要等鼠标动了才生效。
- Mac 触控板没有中键・两键：缩放用双指捏合或滚动，移动用 Shift+拖动。
- 2026-11-02 补上：2線的留線・1/2・2倍間隔（并按 Jw_cad 实测改了两处：画完保留最后的基准线；RR 包絡点在两线之外 = 开口、之间 = 封口），
  中心線寸法，分割的割付・振分・割付距離以下・逆分割・線長割合・馬目地・等角度・円全周，
  寸法的累進・寸法値（作图・R 移动・RR 变更）・一括処理・小数桁・端部（点・矢印・逆矢印）・引出角，
  文字的「連」（L 连结・LL 移动・R 切断），塗り的円環ソリッド（「円・連続線指示」右键）。
- 时钟菜单用户不用，不再往下做。

记号：L = 左键单击，R = 右键单击，LL = 左键双击，RR = 右键双击。
Jw_cad 的规则：L 选任意点，R 选读取点（端点、交点等）；点完第一下鼠标不动，再点一下就算双击（不看间隔时间）。

## 一、画面操作

| 操作 | Jw_cad | 本软件 | 差别 |
|---|---|---|---|
| 左键拖动 | 时钟菜单（左 AM0〜11 时各方向对应命令） | 平移画面 | **不一样** |
| 右键拖动 | 时钟菜单；AM0 = 圆周 1/4 点，AM3 = 中点（线中点／圆心／两点中点），AM6 = 偏移，AM9 = 线上点 | 没有 | **缺** |
| 两键同按（或中键）单击 | 点的位置移到画面中央 | 没有 | **缺** |
| 两键（或中键）拖动 | 右下 = 框选放大，左上 = 缩小 1/2，右上 = 全体，左下 = 前倍率 | 没有 | **缺** |
| Shift + 两键拖动 | 平移画面 | 没有（左键拖动就平移） | 不一样 |
| 滚轮 | 缩放 | 缩放 | 一样 |
| 空命令时左键双击 | 没有这个功能 | 全体表示 | 多出来的 |
| Shift／Ctrl + 点图形 | Shift = 只选书込レイヤ，Ctrl = 只选书込线色线种，两个一起 = 都限定 | 没有 | **缺** |
| R 点没有读取点 | 提示「点がありません」 | 提示「読取点がありません」 | 文字不同 |

## 二、各命令

| 命令 | Jw_cad | 本软件 | 差别 |
|---|---|---|---|
| 線 | 始点・终点 L 任意点／R 读取点；线上右拖 AM0 = 画垂线 | 点的部分一样；右拖垂线没有 | 缺垂线 |
| 矩形 | 同上；寸法指定时点基点后 9 个位置选 | 一样 | — |
| 円弧 | 中心・圆周点 L/R | 一样 | — |
| 2線 | 先点**基准线**，再点**始点、终点**（L/R）才画；LL 换基准线（折线）；RR 点别的线 = 和它包絡 | 点一条线就整条两侧各画一条 | **完全不一样** |
| 中心線 | 第 1、2 个：L = 线・圆，R = 读取点（可以线配点）；然后始点、终点 L/R | 线配点会报错；圆不能选 | 部分不一样 |
| 複線 | L 选线，输入间隔，L 点方向；**间隔不填 = 鼠标位置决定间隔**；**R 选线 = 用上次间隔，R 点方向时和上一条复线自动连角**；选线后在空白处 R = 用前回值 | 必须填间隔；左右键一样；没有连角 | **不一样** |
| コーナー | L 线 A，L 线 B；**R 点线 = 在该处切断** | L/R 都当选线；切断没有 | 缺切断 |
| 伸縮 | L 选线后：**L = 伸到任意点**，R = 伸到读取点；**RR 点线 = 设为基准线**，之后 L 点的线都伸到基准线；R 点线 = 切断 | 第二下 L 是「伸到点中的那条线」，没有任意点；RR 基准线、切断都没有 | **不一样** |
| 面取 | L、L；R 点线 = 切断 | 切断没有 | 缺切断 |
| 消去 | **R 点图形 = 整个删掉**；**L 点线 = 部分消し**（再点始点、终点，L/R；同一点 = 切断） | **反过来了**：L 整个删，R 部分消し | **左右键反了** |
| 範囲選択 | 始点：L 开始框，R 点线 = 选连续线；终点：**L = 不含文字，R = 含文字**；**LL/RR 终点 = 碰到框的也选**；选完以后 L 点图形 = 加选／去掉（文字以外），R = 文字的加选／去掉 | 一开始点到图形就直接加选，不开始框；框里文字总是一起选；不分左右键；没有交叉选、连续线选 | **不一样** |
| 複写・移動 | 选完自动在中心定基点，点位置 L/R 就放；基点変更后再点基点 | 一样 | — |
| パラメ | 框选（线穿过框的被拉伸），选择确定后基点自动在中心，点一下就变形 | 选完后第一下是定基点，第二下才变形 | 多点了一下 |
| 文字 | 初始状态 **L 点已有文字 = 改字／移动，R 点已有文字 = 复写**；放置 L/R | 用按钮切换「書く／移動／変更」，复写没有 | 不一样 |
| 寸法 | 引出线位置、寸法线位置 L/R；**测量的两点不管 L 还是 R 都是读取点**；第 2 个以后：**R 只点终点 = 接着上一个连续**，L = 重新指定始点再点终点；半径・直径：**L 点圆 = 数值在内侧，R = 外侧** | 测量点 L 是任意点；每点一下都从上一点接着画（不能断开重新起头）；半径直径不分内外 | **不一样** |
| 寸法・円周 | 选圆 → 引出线位置 → 寸法线位置 → 始点 → 终点（左回） | 选圆后点一下就画整圈 | 简化了 |
| 寸法・角度 | 原点 → 引出线 → 寸法线 → 始点 → 终点；**LL 点线 = 两线之间的角度** | 原点 → 两点 → 位置；两线角度没有 | 部分缺 |
| 接円 | 1〜3 个：L = 线・圆，R = 读取点；半径不填 = 三个对象定圆 | 只能选两条线＋必须填半径 | 缺 |
| 分割 | L 线 A／R 始点 → L 线 B／R 终点；两个 R 后还要再点：L 点线 = 沿线分，R 空白 = 两点间分；RR = 连续点分割 | 两个 R 就直接两点间分；L 点同一条线两次 = 分那条线（Jw_cad 没有这个操作）；线配点不行 | 不一样 |
| ハッチ | L 一条条点线围起来（最后点回第一条），或 R 点闭合连续线／圆，或「範囲選択」；然后按「実行」 | 点一串坐标围成多边形 | **完全不一样** |
| 多角形・ソリッド | 点 L/R 一串，按「作図」确定；「円・連続線指示」L 保留原图，R 删原图 | 点回第一点就闭合（没有「作図」按钮）；圆・连续线指示没有 | 不一样 |
| 包絡 | 框的终点 **L = 包絡**，**R = 框内消去**，**Shift+L（或左拖 9 时）= 中间线消去** | 终点左右键都是包絡 | 缺 R 和 Shift |
| 属性取得 | L 点图形取属性；**空白处 R = 图层反转显示**（看不见的层也能点） | 左右键一样 | 缺反转 |
| 点・図形・記変・測定・寸解 | L 任意点／R 读取点 | 一样 | — |
| 図登 | 框选 → 「基準点変更」点基点 → 「選択確定」→「《図形登録》」 | 框选 → 選択確定 → 点基点 → 存文件 | 顺序不同，结果一样 |
| AUTO | 空白 L = 画线，空白 LL = 画圆，线上 L→R = 删除等一整套 | 没做 | 缺（已知） |

## 2026-11-02 Mac 试用后补

- 寸法连续：和 Jw_cad 一样，第 2 个以后**右键只点终点**就从上一个终点接着量，左键 = 重新起头。
  Mac 上 **Control+点击 现在算右键**；触控板点下去手指稍微滑一点（不到时钟菜单的距离）也算点击，以前会被吞掉。
- 空格（Jw_cad 键命令 76「方向変更」）：寸法里 0° ⇔ 90° 互切。
