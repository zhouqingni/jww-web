# 第二阶段：画图、改图、存回 .jww

依据：周青妮教新人用的 Jw_cad 练习题（下面的「验收题」）。练习题里出现的命令就是要做的命令，
做到**能用本程序把整套练习题从头做到尾、存成 .jww，并且 Jw_cad 能正常打开**为止。

## 原则

- **先能存，再能改。** 第一步是把 .jww 原样写回去：读 → 写 → 字节完全一致（tests/fixtures 全部）。
  这一步不过关，后面的编辑一律不做，免得把她的图纸存坏。
- **从不覆盖原图。** 「保存」默认另存；覆盖保存前留一份 `.bak`。
- **操作手感照 Jw_cad：** 左键 = 任意点，右键 = 读取点（端点・交点吸附），
  数值输入框（寸法・角度・间隔），属性按写入图层・线色・线种。时钟菜单**不做**（她不用）。
- 坐标、文字尺寸都是图寸（纸面 mm），和读取部分一致；输入的长度是实寸，按写入图层组的缩尺换算。

## DXF（2026-11-02）

- 「開く…」で .dxf も開ける（Mac は「このアプリケーションで開く」にも出る、既定のアプリは変えない）。
  線・円・円弧・楕円・ポリライン（ふくらみ）・スプライン・点・文字・MTEXT・ソリッド・ハッチ（塗り潰し・模様）・
  ブロック（分解）・寸法（分解）・引出線を読む。縮尺は図の大きさから自動（A3 に入る一番小さい標準縮尺）。
  用紙に掛かっていない図は用紙の中央へ移す。画層は Jw_cad 形式の名前（_a-1_名前）なら元のレイヤへ。
  読めないもの（3D メッシュ、画像、ペーパー空間）は読込後のメッセージに数を出す。バイナリ DXF は不可。
- 「DXF 出力…」：R12・Shift-JIS・実寸。レイヤ名は Jw_cad の「レイヤ名に番号を付加」と同じ形なので、Jw_cad で読むと元のレイヤ・名前に戻る（本機の Jw_cad で確認）。
- 手元の DXF 357 個を全部読ませて、エラーはバイナリ DXF の 1 個だけ（tests/dxf.rs の all_local_dxf）。
- `dxfconv` で .dxf ⇔ .jww をコマンドで変換できる。DWG はまだ（本機には ODA File Converter がある）。

## ペン（2026-11-02）

- 左のパレット「ペン」：クリック = 角の点、ドラッグ = 滑らかな点（押した所が点、離した所が出ていくハンドル、反対側に入るハンドル）。
  右クリック・右ドラッグは読取点。始点をクリック（またはドラッグ）で閉じて作図、Enter・「作図」で開いたまま作図、BackSpace・「一つ戻す」で一点戻す。
- 作図すると 1 区間を「分割数」本の線にして、全部同じ曲線属性（Jw_cad でも一本の曲線として選べる）。.jww にはベジェがないので、後からハンドルは動かせない。
