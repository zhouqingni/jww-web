# JWW Viewer

Mac（也能在 Windows 上跑）原生的 Jw_cad 图纸查看器：打开 .jww / .jw$，看图、开关图层、输出 PDF。

不含 Jw_cad 的任何代码。.jww 是照 Jw_cad 官方公开的格式说明
（https://www.jwcad.net/jwdatafmt.txt）自己读的。

## 现在能做的

- 读 .jww / .jw$（Ver.4.20〜7.x 实测 92 张全部读通）：线、圆弧・椭圆、点、文字、寸法、实体（ソリッド）、块（ブロック）
- 画面：Jw_cad 的画面色・线宽・线种（虚线、点划线），图层组・图层开关
- 滚轮 / 双指捏合 = 缩放，拖动 = 平移，双击 = 全体表示
- PDF：打印色 / 黑白、打印线宽（1/100mm 或 dpi 单位）、打印倍率，矢量输出，文字是轮廓
- 「印刷枠」：点一下按钮，再点图面，红框就移到那里；PDF 印的就是红框里的部分

- 存 .jww、作图・编辑命令（第二阶段 A〜E 组，见 docs/stage2.md），塗り・ハッチ・測定・整理

## 公司的环境设定和快捷键

默认读 `assets/company.jwf`（她的「1カラー書き込み用zhou2.jwf」），上面工具条「環境設定…」可以换别的 .jwf（记住到下次）。

- 新規图纸：图层组名・缩尺（[A] S=1/100 等）、图层名（通り芯・既設・鉄骨…）、文字种、线色
- 换写入图层时，线色・线种照 jwf 的图层别设定自动换（例：通り芯 = 线色1・一点鎖1）
- 键照 jwf 的 KEY 页：A〜Z 直接按 / Shift+键、F2〜F9；空格 = 線のとき「水平・垂直」切替；
  Esc = 做到一半就取消这一步，否则「戻る」；Shift+Esc =「進む」；Tab = 属取。
  本程序还没有的命令（建具・曲線・パラメ等）按了会在状态栏提示

## 图层组・图层バー（右边）

照 Jw_cad：方块 = 图层组，圆 = 书込组里的图层。左键：編集可能 → 非表示 → 表示のみ → 編集可能；
右键：设为书込（红框）。下面有紫线 = 这一层有图形。All = 全部编集可能，× = 书込以外的组全部非表示。

## 编译

Windows（开发用）：Rust（GNU 版）＋ MinGW，产物路径见 `.cargo/config.toml`。

```bash
cargo build --release --bin jwwview
```

Mac：推到 GitHub 后由 `.github/workflows/mac.yml` 在云端 Mac 上编译，
做出 Intel ＋ M 芯片通用的 `JWW Viewer.app`（Actions 页面的 Artifacts 里下载）。

## 第一次在 Mac 上打开

没有 Apple 的开发者签名，第一次双击会被拦。做法：在「JWW Viewer.app」上 **右键 →「打开」→「打开」**，
之后就能正常双击了。

## 测试用的小工具

- `jwwdump <文件或文件夹>…`：批量读，报告读不了的文件
- `jww2pdf [--color] [--paper A3] in.jww out.pdf`：不开窗口直接出 PDF
